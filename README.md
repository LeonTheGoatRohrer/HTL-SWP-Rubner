# HTL Python Coursework — SWP Rubner

Existing Python exercises and local coursework solutions: control flow, list comprehensions, lottery examples, object-oriented programming, inheritance, magic methods and poker-hand evaluation.

## Setup and use

Use Python 3.11 or a compatible interpreter. The exercises are standalone scripts rather than a packaged application. For example, run `python Lotto.py` in a terminal. Inspect each script before execution; some prompt for console input or open a GUI. Poker checks: `python -m unittest discover -s Pokerspiel -p test_poker.py`.

Some examples use Python's tkinter/Pillow-style image support; their graphical assets and optional dependencies must be supplied as required by the corresponding script. No database or live service credentials are needed by the reviewed exercises. IDE credentials, cloned teacher-repository duplicates and another student's explicitly named test example are excluded from the new selection.
